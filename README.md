# Gabi Ads — Portfolio Website

Responsive Google Ads and PPC specialist portfolio built with React, TypeScript, TanStack Start and Tailwind CSS.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Deploy to Vercel

Import this GitHub repository into Vercel and keep the detected TanStack Start framework settings. Use `npm run build` as the build command.

All campaign case studies and sample dashboard information are demonstration material. They are not verified client campaign results. Do not present illustrative figures as actual performance.
